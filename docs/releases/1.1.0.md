# GalWeChat 1.1.0

本次更新改的是源码。完全退出并重新打开客户端后才会生效。

### 人物画像

- **MBTI 可以按聊天习惯累计**：不再要求对方亲口说出性格偏好。总括题只判断有没有反复出现的习惯，不能把已经看出来的某一轴丢掉。问候、应答或孤立的一句话仍然不算偏好。
- **判断题目已更新**：版本改为 `mbti-chat-evidence-v4`。展示门槛不变，仍是 100 条有效文本、30 条证据，以及 0.2 的分差。已有画像不会自动重算，需要在画像页点击「更新画像」。

### 意图识别与回复指南

- **两块内容分得清**：意图识别在上，回复指南在下。标题分别是 `[意图识别]` 和 `[回复指南]`。
- **关掉回复指南不再冒出「分析中」**：只有开关开着、任务确实还在跑、而且这条消息还没有结果时，才显示「分析中」。关掉开关不会取消已经发出的这一轮，也不会因此再请求模型。
- **分析起点只在本次打开有效**：重新打开后不继承上次选的起点，已经分析过的结果仍然保留。
- **没选起点时只看旧结果**：标题旁显示「当前未选择分析起点，正在显示过往分析内容。」和「选择分析起点后，新消息将自动进行分析。」打开回复指南不会再自动挑一条消息当起点。
- **选中起点后只补缺口**：对应开关开着时，从该消息到最新、以及之后新来的消息里，当前风格还没有结果的才会分析。两个开关都关着时，只记住起点。起点仍然只能往更早移动；早于服务端最近 500 条时仍提示「这条太早」。
- **「指南风格」改名为「分析风格」**：选项仍是「恋爱战术」和「通用解读」，选择按会话记住。使用 API 时，意图识别和回复指南跟随同一种风格。本地模型的意图识别提示词这次没有改。
- **旧的意图识别结果留在「通用解读」**：不会为了换风格把已经保存的通用结果再分析一遍。恋爱战术没有旧结果。
- **换风格时按缺口确认**：没选起点，或这种风格从起点到最新都已有结果，就直接切换显示。还有缺口时才弹出确认框；确认后只分析缺少的消息，取消则回到原来的风格。

### 截图

- **截图可以复制到剪贴板**：当前 Electron 已不再提供旧的图片写入接口，复制因此一直失败。现已改用新的剪贴板接口写入 PNG。截图区域若因缩放多出一像素，会先收到窗口内部再截。

### 设置与显示

- **上下文大小增加说明**：在「通用设置」的 API 接入里，「上下文大小（tokens）」旁边有一个「说明」按钮。点开后在屏幕中央显示本软件的用量、推荐数值和常见模型参考，底部「关闭」可以退出。
- **意图识别卡片不再发糊**：分析完成后留下的位移会让这块文字在 Windows 缩放下被单独栅格化。已去掉这层位移，并让意图识别卡片的字号与回复指南一致。
