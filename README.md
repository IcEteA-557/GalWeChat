# GalWeChat

Windows 上的只读微信聊天分析客户端。当前版本 **1.1.0**。

意图识别 · 回复指南 · 人物画像 · 聊天助手

</div>

GalWeChat 读取本机已经登录的 Windows 微信 4.x，在本地查看会话，并分析情绪、意图和人物画像。回复草稿和助手建议只留在软件里，不会发到微信。

分析可以用本机的 [Laya](https://github.com/NandhaKishorM/laya) 多语言模型，也可以改用 Anthropic、Responses、Chat Completions、Gemini 或 Ollama 兼容接口。微信数据通过 [wechatauto-replica](https://github.com/fanyuantaier/wechatauto-replica) 只读获取。

## 运行

仓库里是源码。克隆后在本机安装依赖，再用 `npm start` 打开窗口。

需要 Windows 10/11 x64、Node.js **24.11.1**、Python **3.14** 和 npm。

```powershell
npm ci
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-deps -r python-requirements.lock.txt
npm run setup:advisor-engine
npm start
```

要用本地 Laya 时，先执行 `npm run setup:models`，或进软件后再下载。只使用 API 可以跳过。模型约 681 MB，下载后会校验 SHA-256，默认放到 `.models/laya`。`LAYA_MODEL_DIR` 或 `--dir` 可以改位置。

`npm run start:service -- --no-open` 只启动本地桥接服务。

首次使用：

1. 用 Windows 微信 4.x 登录要查看的账号。3.x 不支持。
2. 执行 `npm start`。账号还在准备时，界面可以先打开，状态在「设置 → 管理账号」查看。
3. 在「设置 → 通用设置」选择模型。本地模式下载或指定 Laya 目录；API 模式填写地址、密钥、模型和上下文后测试并启用。
4. 点左侧搜索框旁的「＋」，或到「设置 → 信息列表」，把要看的会话加进来。
5. 打开聊天后使用「意图识别」和「回复指南」，或进入「人物画像」。

自动找不到微信数据时，在「设置 → 通用设置 → 聊天记录路径」选择 `xwechat_files` 或账号目录。选完目录后仍要微信处于登录状态。

## 功能

### 聊天

软件只读单聊、群聊、联系人和头像。图片消息显示为 `[图片]`。输入框里的文字是草稿：Enter 复制到剪贴板，不会发送。

- **意图识别**：在对方消息下显示情绪和意图短标签，例如「开心」「邀约」。判断会参考近期聊天和已有画像。关掉再打开会恢复已有结果。
- **回复指南**：按当前会话生成解读卡，包含可能性、程度和建议。风格可选「恋爱战术」或「通用解读」。点「分析起点」后，从选定的一条对方消息分析到最新。卡片标明这是模型推测。
- **可能的回应**：单聊里预测对方接下来可能怎么回。群聊没有这项。
- **截图**：框选一段消息，把图片复制到剪贴板。
- **历史**：可以翻更早的消息，按关键词或日期查找并回到上下文。

### 人物画像

从左侧或聊天工具栏进入。单聊看对方，群聊可以在「群整体」和成员之间切换。

- 单聊显示好感度数值和等级，并随新消息更新。
- MBTI 按 E/I、S/N、T/F、J/P 显示聊天倾向。有效文本满 100 条后解锁，依据不够的维度保持未确定。
- 互动风格是六维雷达：表达活力、幽默表达、情绪平和、话题主动、关怀支持、亲近表达。
- 页面同时给出常聊内容和一段摘要。
- 本地和 API 使用同一套累计打分。再次进入时先显示上次结果，只继续分析新消息。

「重置会话分析」清除当前模型来源下、这个会话的消息标签和全部画像。「重置画像」只清除当前对象或选中的群成员。其他会话、其他模型来源和助手记录会留下。

### 聊天助手

左侧「助手仓库」管理助手。聊天工具栏的「聊天助手」在主窗口右侧打开固定面板，可以结合当前会话问交流建议、整理内容或写回复草稿。

助手从 GitHub 地址、本地 `SKILL.md`、技能目录或 ZIP 导入。名称、说明、欢迎语、提示词和技能可以再改。对话按微信账号、会话和助手分开保存。输入 `/reset` 只清空当前助手在当前会话里的对话。

助手使用设置里的生成式 API 或 Ollama，模型需要支持工具调用。本地 Laya 不负责写助手回答。助手只能读本轮给出的当前会话材料和选中的技能文本，不能发微信、跑命令、改文件，也不能看其他会话。更细的用法见 [助手说明](docs/advisor.md)。

### 模型与账号

- 默认本地 Laya。API 画像至少需要 12288 tokens 上下文，程序会按容量分批。
- 本地结果和每个 API 来源分开保存，可在设置里分别查看和清除。
- 本地分析可以调并行数，或打开「跟随负载」。设备可选 CPU / GPU，GPU 不可用时回退到 CPU。
- 每个微信账号使用自己的数据库。清除账号只删除 GalWeChat 里的副本、分析和画像，不删除微信原记录。清除当前账号后软件会退出。
- 界面可以切换深色、浅色和缩放。

## 数据与使用边界

- 本地模式的推理留在本机，服务只监听回环地址。
- 打开 API 后，消息分析和人物画像会把当前批次的聊天文本发给你配置的服务。
- 使用聊天助手时，当前会话材料、摘要、所选技能和助手对话会按需要发给该服务。
- 只读取自己有权访问的账号和聊天。分析结果是模型推测，不能当成对方的真实想法、心理诊断或官方性格测试。
- 软件不导出微信聊天记录，也不自动发送消息。
